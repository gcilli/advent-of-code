# Advent Of Code

All solutions are provided in (hopefully) both C++ and Python. Run:

    # 2025 - Day 1 - C++ solution
    bazel run //2025/day01:cppmain
    
    # 2025 - Day 1 - Python solution
    bazel run //2025/day01:pymain

**Note**: as per Advent of Code's Code of Conduct, I am not allowed to share my inputs. Hence, inputs have to be provided manually. Year YYYY Day DD expects the `input.txt` file to be in `YYYY/dayDD/inputs/input.txt`.
